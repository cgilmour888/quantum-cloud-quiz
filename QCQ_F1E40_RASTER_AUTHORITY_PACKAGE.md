## Mission

## Runtime model

1. Existing F1E37 `openAux()` renders the authoritative live data/controller view.
2. F1E40 captures only the live values needed by the selected display.
3. The approved raster authority replaces the physical monitor canvas inside `#auxMonitor`.
4. Registered socket overlays replace baked sample values where live data is required.
5. Transparent controls bind Dataset and Settings interactions without modifying the surrounding scene.
6. Closing the auxiliary monitor restores the untouched quiz tablet.
