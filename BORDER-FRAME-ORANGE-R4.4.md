# BorderFrameEngine R4.4 — Persistent Orange Plasma

R4.4 corrects the R4.3 orange channel's momentary appearance. The orange network now contains a permanent counter-clockwise carrier current, four traveling plasma heads, long pressure tails, a non-zero voltage floor, local halo sampling, and quality-independent minimum visibility.

The approved cyan clockwise channel is unchanged. Purple remains staged in the default dual mode. Protected MASTER artwork, masks, placard, music icon, dashboards, tablet, altar, and gyroscopes are unchanged.

Use:

- `/` — cyan + persistent orange
- `/?qcq-border-channel=cyan` — approved cyan only
- `/?qcq-border-channel=orange` — persistent orange only
- `/?qcq-border-channel=dual` — cyan + persistent orange
