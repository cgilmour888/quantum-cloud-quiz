## Non-negotiable native-build rules

- the conceptual artwork is art direction only;
- no full-page production background impersonating a website;
- no dynamic text in raster assets;
- no overlay geometry used to conceal baked content;
- native HTML controls, React components, SVG geometry, and independent environment systems;
- all significant decisions are written to repository files;
- each milestone ends with a recovery archive and continuation prompt.
