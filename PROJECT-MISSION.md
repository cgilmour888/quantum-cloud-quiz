# Project Mission Statement

Quantum Cloud Quiz exists to train users for the AWS Certified Cloud Practitioner examination while also supporting independently uploaded question-and-answer datasets for other examinations.

The visual interface, animation systems, game rules, audio behavior, scoring, dashboards, effects, and interaction model remain fixed. Only the active question dataset changes. Each uploaded dataset must be validated and normalized into the same quiz schema before gameplay begins.

The approved MASTER artwork is the immutable visual foundation. Future work activates the artwork through independent transparent animation engines rather than repainting or replacing the MASTER.
