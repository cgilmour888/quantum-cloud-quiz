# A2.3 Visual Inspection Checklist

- [ ] Shell position, scale, angle, and silhouette match the original.
- [ ] Original tablet remains invisible beneath the replacement.
- [ ] Question title is visible.
- [ ] Question copy is visible and contained.
- [ ] Answers A–D are all visibly populated.
- [ ] Option E remains available through paging where required.
- [ ] Hover/focus does not hide answer copy.
- [ ] Single-select works.
- [ ] Multiple-select works.
- [ ] Selected, correct, and incorrect states remain distinct.
- [ ] Scoring and progression work.
- [ ] No full-tablet reading overlay opens.
- [ ] Dashboard remains unchanged.
- [ ] No diagnostic outlines appear on the clean route.
